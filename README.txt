INNERLY — Private Wellness & Relationships
PWA-ready package for iPhone and Android

WHAT IS INCLUDED
- Responsive front-end prototype
- PWA manifest and service worker
- Android app icons (192px and 512px)
- iPhone home-screen icon

PUBLISHING
1. Upload the contents of this folder to a static HTTPS host (Netlify is a suitable option).
2. Open the published HTTPS URL in Safari on iPhone.
3. Tap Share > Add to Home Screen.
4. On Android, open the same URL in Chrome and choose Install app / Add to Home screen.

IMPORTANT
This remains a front-end prototype. It does not yet connect to an AI model, user accounts, a database, partner syncing, or a secure admin backend. Do not enter real sensitive personal information until those features and privacy controls have been implemented and reviewed.
